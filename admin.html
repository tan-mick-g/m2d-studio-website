Studio Screen

Open Live Screen ↗

Mix photos, posters, and videos in a continuous loop. Drag the move handle, use the arrows, or enter a position number and press Enter to move a slide. This page is not linked in the website navigation.

Display Settings

These defaults apply to the whole playlist. Each image can have its own duration.

Videos play to the end. Sound also depends on the TV volume and AbleSign’s browser permissions; playback falls back to muted if sound is blocked. Use direct video files, such as MP4, rather than YouTube or social-media page links.

Screen Background

Your background image fills the screen behind fitted media and the loading screen. The color above remains the fallback. A slide’s blurred-image setting takes precedence.

Loading & Empty Screen

Turning off Show Loading Screen hides its image and message but keeps your design saved. Only the background remains while loading. Between-media playback also requires Show Loading Screen; its timer starts after an image finishes or a video ends. The screen stays visible if the next item needs extra time to load.

Shown while the first media loads, when the playlist is empty, or when all media fails. The TV remembers the last published design for its next startup.

Ready for AbleSign

Add your website’s /screen address as a Website in AbleSign. Allow enough display time for the playlist. The screen checks for published changes every minute and applies them between slides. Website playback requires an internet connection.

Screen Navigation

Applies while browsing videos, packages, schedules, or classes. A selected video plays to the end before returning. Back to Playlist returns immediately.

Packages, Schedule, and Classes are managed here independently of the looping playlist.

Classes Button

For Rezerv, use the official Embed Widget URL. Regular booking pages such as /class may block display here. Rezerv embedding guide

The page opens inside Studio Screen and rotates with it. The website must allow embedding. Activity inside an external webpage cannot reset the return timer; use a longer timeout above if needed.

Switch modes any time. Both the URL and image stay saved. Leave the selected source empty to show a “Classes information coming soon” message.

Video Display Names

These titles appear in the Videos gallery. Internal slide names stay unchanged. Blank titles appear as Video 1, Video 2, and so on.
